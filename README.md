# 经纬

当前源码为 1.0.0-rc.4，已完成我的情况三问、金额与天数费用估算、七版历史判断变化及默认读者界面。本轮按同一应用、同一用户资料目录更新；实际安装与重开检查见 evidence/rc4-reader-path-20261005。此前无 Git 发布历史，新建立的本地基线与后续构建边界见 [源码与构建追溯](docs/源码与构建追溯.md)。

财经阅读与有依据的基金研究桌面软件。Windows 主交付为 x64 NSIS 安装器，Mac 提供 Apple Silicon DMG；安装后直接打开，不需要 Node、终端、数据库服务或模型密钥。

## 普通使用

首页以沪深300研究为主。我的情况的三个选择仅保存在本机，可跳过、编辑和重置；长期计划不自动等同于维持持仓。比较页用金额和已确认持有自然日估算两只C类的销售服务费与赎回费，实际全部费用和未来费率仍未知。判断变化逐项比较第1至7版历史人工研究；没有运行触发记录就显示未记录。旧宏观文章保留在历史资料入口。当前公开种子有15个已刊版本，资料及判断保留原日期，没有自动制造当天更新。

阅读、搜索、收藏、基金比较与历史无需 Key。已保存内容可离线阅读，原站链接与取得新资料需要网络。应用运行时自动核查沪深300及两只已支持基金；退出后停止，下次打开按上次核查时间补查。免费更新设置与一键关注保存在本机。失败来源保留最后成功记录及原日期，其他来源继续可用；不会把旧数据写成今天的新结论。重启不恢复付费授权。

默认导航为阅读、我的情况、比较、判断变化。采集、编辑、刊发和AI设置在默认关闭的维护模式中，可从应用帮助菜单进入。AI解读须由使用者亲自在软件内配置密钥、费用上限及授权。Windows 用系统 DPAPI、Mac 用系统安全存储保护主动保存的密钥；加密不可用就拒绝保存，不回退为明文。首次未配置启动不读取系统凭据。

## 发行与验收

`releases/1.0.0-rc.1/` 有 Windows 安装器、Mac DMG、Mac 应用ZIP以及单独的源码ZIP和SHA256清单。使用说明随发行提供。

Mac arm64 在 macOS15.6 已从DMG实际安装，完成无Key阅读、比较、搜索、收藏、历史、退出、重启和残留锁恢复检查；取数失败与离线信号在隔离安装版受控检查，未改变系统网络。Windows x64 已交叉构建并检查程序架构、版号、图标及包内资源，未在Windows设备原生验收；安装、运行、DPAPI权限和卸载仍待实测。发行包未使用付费开发者证书或公证，不宣称所有系统无安装提示。

此前安装包仅带公开已刊内容和必要资源，不带开发预算、任务、日志、个人路径或凭据。当前源码另带有原日期及出处的公开资料缓存，用于网络失败时保留真实净值记录；它不是模型研究或模拟运行历史。每个用户的资料、收藏和有限备份保存在系统用户目录。旧工程的数据及原预算保持，不迁入发行种子。

## 构建源码

以下命令面向开发者；使用安装包的读者不需要执行。

要求 Node ≥24.11 与 npm。依赖锁在 `package-lock.json`，Electron40.10.6、electron-builder26.15.3。仅从官方依赖与运行时地址获取。

```sh
npm ci --ignore-scripts
npm run desktop:prepare
npm run desktop:mac
npm run desktop:win
```

Mac 与 Windows 构建串行进行。默认构建会取得官方运行时；已有验证后的运行时可用 electron-builder 的 `electronDist` 参数。Mac DMG辅助下载受阻时，可用系统hdiutil将构建应用与Applications快捷方式制作成标准DMG。本轮就是这样制作；没有修改系统安全或网络设置。

```sh
npm run typecheck
npm test
```

测试预载隔离设置，只使用临时目录，拒绝生产数据及其符号链接别名。后台继续保留 web/api/worker 结构，桌面主进程管理API与SSR的动态回环端口，不依赖外部Node进程或固定4410端口。基金免费核查默认运行并保留跨启动检查点；模型研究仍需本机设置及明确授权。PostgreSQL/pg-boss 不再是依赖；可选 worker 的周期采集仅随该进程运行，未安装系统服务。

## 研究及许可边界

目前覆盖沪深300与007339、005658两只同方向候选，尚无全市场筛选或首次配置指导。现有七版基金稿诚实标为历史人工研究。当前源码以官方事实包、确定性指标、专用模型输出和可检查条件形成新的研究版本，首页、文章与专题共同消费；没有有效模型结果时不造新判断。模型真实基金研究尚未运行，不将条款变化当买入信号，不以不同跟踪口径排名。真实模型请求此前两次：一次失败，一次宏观错引经编辑修改后刊发；本轮没有付费请求。模拟闭环不能证明真实基金AI研究或投资效果。

受保护工程中15版恢复记录为12个完整档案逐字段恢复、3篇编辑档案重建，部分材料与任务历史有缺口，详情在独立文书与证据记录。此发行没有补造历史。
