# 经纬

经纬按公开估值规则给出 11 个指数的新增资金与持仓判断：A股为沪深300、中证500、上证50、中证1000、创业板指、科创50、中证红利；美股港股为纳斯达克100、标普500、恒生指数、恒生科技。判断随对应来源的估值变化，每次改判可回看、可复算。

即将发布 **1.0.0-rc.5**。Mac 提供 Apple Silicon DMG 与应用 ZIP，Windows 提供 x64 NSIS 安装器。安装版自行启动阅读服务，无需 Node 或终端。源码及构建追溯见[源码与构建追溯](docs/源码与构建追溯.md)。

## 判断怎样形成

11 个指数采用同一套估值分位规则 v2；以「沪深300估值分位规则 v2」（`csi300-pe-ttm-10y-v2`）为例，取滚动市盈率（PE TTM），计算近 10 年数据读数中估值不高于当日的比例，包括当日。历史不足十年时使用全部已有数据，至少积累 5 年才开始计算。

|估值分位|区域|新增资金|已有持仓|
|---|---|---|---|
|低于第 30 百分位|偏低区|可分批新增|继续持有|
|第 30 至低于第 70 百分位|中间区|按原计划，不额外追加|继续持有|
|第 70 至低于第 90 百分位|偏高区|暂缓新增|继续持有|
|第 90 百分位及以上|高位区|暂停新增|可按计划再平衡|

新区域在每日数据下连续 **5 个交易日**成立、每周数据下连续 **2 个周读数**成立才改判，两者都约等于一周；离开已确认的区间还要比边界多越过 **5 个百分点**（v2 缓冲，例如中间区升到偏高区要到第 75 百分位，偏高区回到中间区要低于第 65 百分位）。沪深300不加缓冲的 v1 在同一数据上改判 31 次、其中 7 次在 45 天内反转；v2 改判 17 次、反转 1 次，各区间之后三年收益的排序两版一致。尚在确认中时保留原判断并显示进度。回算序列首日作为初始区域，之后的区域改变应用连续确认规则。已有持仓的再平衡以原定比例为条件，只调整超出部分。

收益回放和股债对照（ERP）覆盖沪深300、中证500、上证50、中证1000、中证红利五个指数；它们有中证全收益指数和中国十年期国债收益率可对应。五个指数各换十组参数，50 次中有样本区间的三年年化均值排序在 49 次成立；仅 18 次四档齐全，其中 17 次完整排序成立。中证1000缺偏高、高位区样本，中证红利缺高位区样本，不能声称它们四档完整排序成立，见[规则稳健性](docs/规则稳健性.md)。科创50、创业板指和四个境外指数只给估值判断和改判记录。

沪深300、中证500、上证50、中证1000、科创50、中证红利这 6 个指数使用中证指数官网每日估值；创业板指及纳斯达克100、标普500、恒生指数、恒生科技使用蛋卷基金公开的每周估值，注明“蛋卷基金（第三方）”。中证不发布这 5 个指数的估值，美股、港股指数也没有免费的官方长期 PE 历史，因此采用第三方数据。各指数起点、数值与来源见[指数覆盖](docs/指数覆盖.md)。

沪深300数据来自[中证指数沪深300官方页](https://www.csindex.com.cn/#/indices/family/detail?indexCode=000300)与其[历史估值接口](https://www.csindex.com.cn/csindex-home/perf/indexCsiDsPe?indexCode=000300&startDate=20110628&endDate=20260930)。本版随包保留沪深300 **2011-06-28 至 2026-09-30、3,788 个数据日**，可离线复算；应用打开时按各指数同一来源补齐新数据，失败保留最后可用资料及原日期。「数据日」按对应来源返回记录计数。

`GET /publication/judgment` 本次核对输出：数据截至 **2026-09-30**，PE **13.15 倍**、第 **48.8 百分位**，处于中间区；新增资金「按原计划，不额外追加」，已有持仓「继续持有」。当前从中间区出发的改判边界约为 **12.22 / 14.41 / 15.33 倍**（已含缓冲），随历史窗口变化；实际改判依分位与连续确认计算，不能把当前边界当永久阈值。

## 回算与软件运行中的改判

判断变化页按各指数数据频率应用同一规则；以沪深300为例，展示 2016-09-08 以来的 **17 次改判**（中证500 9 次、上证50 22 次）。上次为 **2026-09-07**：偏高区 → 中间区，当日 PE **13.64 倍**、第 **58.1 百分位**。

上述沪深300、中证500、上证50记录全部来自官方历史数据的回算，**不是当时发布的判断**；其他指数使用各自对应来源的历史数据回算。规则以 `2026-10-06` 区分回算与软件运行中的记录；本次输出的软件运行中改判数为 **0**。回算展示同一规则在历史中的改变。完整数据、规则源码与接口输出可以交叉核对：

- [规则](packages/backend/valuation-rule.ts)
- [数据来源与增量核查](packages/backend/valuation-history.ts)
- [随包官方历史](packages/backend/csi300-pe-seed.ts)
- 本次实际读取：`GET /publication/judgment`

每个指数都有独立复算，例如 `node scripts/replay-rule.ts --index NDX`。以沪深300为例，`npm run replay:rule` 不调用软件的规则代码，只用随包官方数据从头重算每天的分位、区间和全部改判，结果与软件逐日一致。沪深300 的结果在 [changes.csv](exports/rule-replay/000300/changes.csv)（17 次改判）和 [daily.csv](exports/rule-replay/000300/daily.csv)（每日分位与区间），中证500、上证50在同目录的 000905、000016 下，可直接用表格软件打开。

## 普通使用

1. **阅读今日判断**：从顶部「今日判断」进入首页，可在「全部指数」一览中切换指数；先看规则判断、估值位置和改判边界，再从「我的 → 我的情况」设置个人情境。下方「延伸阅读」提供费用比较、判断变化与客户说明入口，「往期解读」保留历史文章及其资料日期。
2. **设置我的情况**：从「我的 → 我的情况」进入，选择长期计划、当前持仓与期限。三个选择及可选的每月定投、闲钱金额只保存在本机，可跳过、修改、重置。同一公开判断会换成对应情境的说法；短期资金与支持范围外持仓另有提示。
3. **回看判断变化**：从首页「…的 N 次改判 →」进入 `/changes`，用页顶「‹ 今日判断」返回；查看估值曲线、每次改判的日期、PE、分位及回算标记，在「规则与口径」核对计算方法。历史人工解读的正文修订另行保留。
4. **比较两只 C 类**：从「研究 → 费用比较」进入，输入金额与已确认持有自然日，估算 007339、005658 的销售服务费与赎回费；说明及来源随表保留。

阅读、搜索、收藏、费用比较与规则改判记录无需 Key；已保存内容可离线阅读。原站链接与取得新资料需要网络，应用退出后免费核查停止，下次打开按检查点补查。历史人工文章保留自己的日期和原观点，当前行动判断以首页公开规则为准。

AI 解读需要用户自备 Key，并在维护模式中配置费用上限及授权。AI 研究链使用规则结果作为证据，新增资金与持仓立场须与规则一致；本轮未调用付费模型。用户主动保存的密钥由系统保护，费用授权在累计上限内长期有效，取消勾选并保存即撤销。设置从右上角齿轮进入；维护模式从应用帮助菜单启用后，可在设置中进入模型连接、内容维护。

## 构建源码

要求 Node ≥24.11 与 npm，依赖锁在 `package-lock.json`。Electron 40.10.6、electron-builder 26.15.3。

```sh
npm ci --ignore-scripts
npm run typecheck && npm test
npm run desktop:prepare
npm run desktop:mac
npm run desktop:win
```

Mac 与 Windows 构建串行进行。隔离验收从项目目录运行，临时目录必须与日常用户资料分开：

```sh
JINGWEI_DESKTOP_DATA_DIR="$(mktemp -d /tmp/jingwei-rc5-XXXXXX)" npx electron .
```

桌面主进程自行启动 API 与阅读服务。各用户的资料、收藏与有限备份保存在系统用户目录。

## 边界与许可

规则不预测涨跌，不保证收益；估值偏低仍可能继续下跌。它面向长期资金，未纳入完整个人资产、收入、负债及风险承受能力，不替用户确定配置比例或执行交易。估值规则与持仓体检覆盖上述 11 个指数的普通跟踪基金（指数基金、ETF、联接、LOF），按所跟踪指数给判断；指数增强、行业和策略变体不套用，只计入方向与重复。费用比较仍围绕 007339、005658 两只沪深300联接 C 类，尚无全市场选基；同时持有两只不增加市场方向分散。官方记录不承诺完整覆盖交易日历。费用估算未覆盖全部费用和未来执行安排，报告基准口径不同不能直接排名跟踪优劣。回算展示规则改变，不证明投资有效性。

尚无真实试读效果、收益验证或银行合作；真实付费基金 AI 文本质量与研究效果、Windows 原生安装运行及卸载待验证。旧人工文章与模型文本均不能替代当前规则口径，历史缺口不补造。技术参考 AIHOT 固定提交 `035f7b7f6e26cf203562ddd6065ff7adc1bb0c07`，保留 `LICENSE-AIHOT`、`NOTICE-AIHOT` 及 Electron/Chromium、依赖许可。没有 push、公开部署或正式参赛提交。
