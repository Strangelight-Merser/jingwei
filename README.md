# 经纬

经纬按公开估值规则给出沪深300的新增资金与持仓判断，判断随中证官方估值变化，每次改判可回看、可复算。

即将发布 **1.0.0-rc.5**。Mac 提供 Apple Silicon DMG 与应用 ZIP，Windows 提供 x64 NSIS 安装器。安装版自行启动阅读服务，无需 Node 或终端。源码及构建追溯见[源码与构建追溯](docs/源码与构建追溯.md)。

## 判断怎样形成

规则是「沪深300估值分位规则 v2」（`csi300-pe-ttm-10y-v2`），同一规则也用于中证500、上证50。取沪深300滚动市盈率（PE TTM），计算近 10 年数据日中估值不高于当日的比例，包括当日。历史不足十年时使用全部已有数据，至少积累 5 年才开始计算。

|估值分位|区域|新增资金|已有持仓|
|---|---|---|---|
|低于第 30 百分位|偏低区|可分批新增|继续持有|
|第 30 至低于第 70 百分位|中间区|按原计划，不额外追加|继续持有|
|第 70 至低于第 90 百分位|偏高区|暂缓新增|继续持有|
|第 90 百分位及以上|高位区|暂停新增|可按计划再平衡|

新区域连续 **5 个数据日**成立才改判；离开已确认的区间还要比边界多越过 **5 个百分点**（v2 缓冲，例如中间区升到偏高区要到第 75 百分位，偏高区回到中间区要低于第 65 百分位）。不加缓冲的 v1 在同一数据上改判 31 次、其中 7 次在 45 天内反转；v2 改判 17 次、反转 1 次，各区间之后三年收益的排序两版一致。尚在确认中时保留原判断并显示进度。回算序列首日作为初始区域，之后的区域改变应用连续确认规则。已有持仓的再平衡以原定比例为条件，只调整超出部分。

数据来自[中证指数沪深300官方页](https://www.csindex.com.cn/#/indices/family/detail?indexCode=000300)与其[历史估值接口](https://www.csindex.com.cn/csindex-home/perf/indexCsiDsPe?indexCode=000300&startDate=20110628&endDate=20260930)。本版随包保留 **2011-06-28 至 2026-09-30、3,788 个数据日**，可离线复算；应用打开时免费核查官方资料，成功后补入估值历史，失败保留最后可用资料及原日期。「数据日」按官方返回记录计数。

`GET /publication/judgment` 本次核对输出：数据截至 **2026-09-30**，PE **13.15 倍**、第 **48.8 百分位**，处于中间区；新增资金「按原计划，不额外追加」，已有持仓「继续持有」。当前从中间区出发的改判边界约为 **12.22 / 14.41 / 15.33 倍**（已含缓冲），随历史窗口变化；实际改判依分位与连续确认计算，不能把当前边界当永久阈值。

## 回算与软件运行中的改判

判断变化页逐日应用同一规则，展示 2016-09-08 以来的 **17 次改判**（中证500 9 次、上证50 22 次）。上次为 **2026-09-07**：偏高区 → 中间区，当日 PE **13.64 倍**、第 **58.1 百分位**。

这些记录全部来自官方历史数据的回算，**不是当时发布的判断**。规则以 `2026-10-06` 区分回算与软件运行中的记录；本次输出的软件运行中改判数为 **0**。回算展示同一规则在历史中的改变。完整数据、规则源码与接口输出可以交叉核对：

- [规则](packages/backend/valuation-rule.ts)
- [数据来源与增量核查](packages/backend/valuation-history.ts)
- [随包官方历史](packages/backend/csi300-pe-seed.ts)
- 本次实际读取：`GET /publication/judgment`

想自己算一遍：`npm run replay:rule` 不调用软件的规则代码，只用随包官方数据从头重算每天的分位、区间和全部改判，结果与软件逐日一致。沪深300 的结果在 [changes.csv](exports/rule-replay/000300/changes.csv)（17 次改判）和 [daily.csv](exports/rule-replay/000300/daily.csv)（每日分位与区间），另两个指数在同目录的 000905、000016 下，可直接用表格软件打开。

## 普通使用

1. **阅读首页**：先看规则判断、估值位置和改判边界，再看「我的情况」。本期解读文章保留标题、日期与一句导读；「资料与口径」默认折叠，需要时展开。
2. **设置我的情况**：选择长期计划、当前持仓与期限。三个选择只保存在本机，可跳过、修改、重置。同一公开判断会换成对应情境的说法；短期资金与支持范围外持仓另有提示。
3. **回看判断变化**：查看估值曲线、每次改判的日期、PE、分位及回算标记，在「规则与口径」核对计算方法。历史人工解读的正文修订另行保留。
4. **比较两只 C 类**：输入金额与已确认持有自然日，估算 007339、005658 的销售服务费与赎回费；说明及来源随表保留。

阅读、搜索、收藏、费用比较与规则改判记录无需 Key；已保存内容可离线阅读。原站链接与取得新资料需要网络，应用退出后免费核查停止，下次打开按检查点补查。历史人工文章保留自己的日期和原观点，当前行动判断以首页公开规则为准。

AI 解读需要用户自备 Key，并在维护模式中配置费用上限及授权。AI 研究链使用规则结果作为证据，新增资金与持仓立场须与规则一致；本轮未调用付费模型。用户主动保存的密钥由系统保护，重启不恢复付费授权。维护模式从应用帮助菜单进入。

## 构建源码

要求 Node ≥24.11 与 npm，依赖锁在 `package-lock.json`。Electron 40.10.6、electron-builder 26.15.3。

```sh
npm ci --ignore-scripts
npm run typecheck && npm test
npm run desktop:prepare
npm run desktop:mac
npm run desktop:win
```

Mac 与 Windows 构建串行进行。隔离验收从项目目录运行，临时目录必须与日常用户资料分开：

```sh
JINGWEI_DESKTOP_DATA_DIR="$(mktemp -d /tmp/jingwei-rc5-XXXXXX)" npx electron .
```

桌面主进程自行启动 API 与阅读服务。各用户的资料、收藏与有限备份保存在系统用户目录。

## 边界与许可

规则不预测涨跌，不保证收益；估值偏低仍可能继续下跌。它面向长期资金，未纳入完整个人资产、收入、负债及风险承受能力，不替用户确定配置比例或执行交易。目前覆盖沪深300与 007339、005658 两只联接 C 类，尚无全市场选基；同时持有两只不增加市场方向分散。官方记录不承诺完整覆盖交易日历。费用估算未覆盖全部费用和未来执行安排，报告基准口径不同不能直接排名跟踪优劣。回算展示规则改变，不证明投资有效性。

尚无真实试读效果、收益验证或银行合作；真实付费基金 AI 文本质量与研究效果、Windows 原生安装运行及卸载待验证。旧人工文章与模型文本均不能替代当前规则口径，历史缺口不补造。技术参考 AIHOT 固定提交 `035f7b7f6e26cf203562ddd6065ff7adc1bb0c07`，保留 `LICENSE-AIHOT`、`NOTICE-AIHOT` 及 Electron/Chromium、依赖许可。没有 push、公开部署或正式参赛提交。
