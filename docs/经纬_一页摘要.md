# 经纬·规则e判——基于公开估值规则与大模型解读的指数基金决策服务方案

作品摘要

参赛方向：财富管理服务（兼顾青年群体服务）

<!-- cover-end -->

## 一、问题

指数基金投资者常问三个问题：新增资金现在投不投，已有持仓要不要动，判断在什么条件下会改变。现有估值工具提供市盈率分位或“温度”，较少直接给出做法和改变条件；银行客户经理逐一解释估值，口径难以统一。

## 二、方案

经纬以指数滚动市盈率在近十年历史中的分位为唯一指标，按 30、70、90 分为偏低、中间、偏高、高位四个区间，为新增资金和已有持仓分别给出做法；离开当前区间需多越过 5 个百分点，并连续确认 5 个交易日（周数据为 2 周）才改判。规则覆盖沪深300、中证500、上证50、中证1000、创业板指、科创50、中证红利、纳斯达克100、标普500、恒生指数、恒生科技共 11 个指数。

围绕这条规则，作品提供今日判断、改判记录与历史收益、持仓体检（截图本机识别）、问经纬（大模型解释、规则约束、逐项核对），以及面向银行的规则卡和客户经理一页说明。

## 三、主要结果

| 项目 | 结果 |
|---|---|
| 当前判断（沪深300，2026-09-30） | 市盈率 13.15 倍，第 48.8 百分位，中间区：新增资金照常定投，不加仓；已有持仓继续持有 |
| 分区间收益（沪深300，持有三年年化均值） | 偏低区 9.6%，中间区 6.3%，偏高区 3.7%，高位区 −5.1% |
| 参数稳健性 | 十组参数、五个指数，50 次中 49 次保持“估值越低、之后收益越高” |
| 缓冲效果（沪深300，十年） | 改判 31 次降至 17 次，45 天内改回 7 次降至 1 次 |
| 计算正确性 | 独立复算脚本核对 11 个指数全部改判记录，结果一致；297 项自动测试通过 |

注：收益含分红，未扣除基金费用；逐日样本的持有期相互重叠，历史不代表未来。

## 四、应用前景

在工银手机银行“财富—基金”的投教栏目和基金详情页展示规则卡；客户经理在持有期回访时使用一页说明。建议先在一个分行试点 3 个月，以客户能否正确说出当前判断和改变条件、客户经理解释用时是否减少作为衡量指标。

## 五、风险与边界

规则只给出公开规则下的做法，不预测涨跌，上线前需经银行合规审核。创业板指和境外指数使用蛋卷基金的第三方周数据。在两家都发布的 A 股指数上，蛋卷与官方数据得出的判断一致率约 64%–81%（科创50 约 20%），说明来源会影响判断，因此页面标注来源。大模型只解释、不判断，核对不通过时显示规则原文。
