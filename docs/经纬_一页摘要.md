# 经纬·规则e判

基于公开估值规则与大模型解读的指数基金决策服务方案

财富管理服务（兼顾青年群体服务）｜1.0.0-rc.5 · 规则 v2

## 痛点

新钱怎么安排、已有基金怎么看、什么时候会改判？客户需要可追溯的判断依据，客户经理需要一致的解释口径。

## 方案

覆盖11个指数：沪深300、中证500、上证50、中证1000、创业板指、科创50、中证红利，以及纳斯达克100、标普500、恒生指数、恒生科技。以PE TTM近十年分位、30/70/90分档、5点缓冲和日5／周2确认给出判断；大模型围绕规则证据解释。

首页 → 判断变化 → 持仓体检：查看改判与五指数收益回放，导入持仓、确认识别结果、检查规则覆盖与重复配置，并导出体检报告。“我的情况”“费用比较”补充阅读；“机构服务”提供规则卡与客户经理说明。

## 证据

沪深300当前PE 13.15倍、第48.8百分位，中间区；新增资金按原计划、不额外追加，已有持仓继续持有。五指数十组参数中，有样本区间排序49/50次成立；四档齐全18次中17次成立。当前297项测试通过，11指数改判可独立复算。

## 工行落地

基金频道展示规则卡；客户经理用一页说明开展投教与持有期回访；客户导出持仓体检报告。先检验客户理解与解释耗时，再接入银行适当性、审校与留痕流程。

## 风险边界

6指数取中证官方日估值，5指数取蛋卷第三方周估值。A股对照的v2判断一致率20.31%–81.03%，不能互换来源或外推境外准确性。历史收益含分红、未扣基金费用且样本重叠；增强、行业及策略变体不套用规则。模型校验失败展示规则原文。
