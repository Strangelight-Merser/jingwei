# 经纬·规则e判——基于公开估值规则与大模型解读的指数基金决策服务方案

**参赛方向：财富管理服务**｜按公开规则给出、会随证据改变、每次改判可复算的基金判断

**一页摘要｜依据 2026-10-06 的实际接口与当前实现整理｜即将发布 1.0.0-rc.5**

## 问题与产品

面对同一条市场新闻，读者需要知道新钱怎样安排、已有持仓怎样处理，以及什么变化会让结论改口。经纬把沪深300的判断写成公开规则：按近 10 年滚动市盈率分位划区，新区域连续 5 个数据日成立才改判。打开首页即可看判断、估值位置和下一次改变的边界，完整规则、来源和每次改变都能复核。

## 当前判断与核心演示

数据截至 2026-09-30，沪深300滚动市盈率 13.15 倍、第 48.8 百分位，处于中间区；新增资金「按原计划，不额外追加」，已有持仓「继续持有」。当期改判边界约为 12.42 / 14.24 / 15.33 倍：对应偏低、偏高与高位区，按连续确认决定改变。

演示依次展示：首页判断 → 改判边界 → 2026-09-07 偏高区转为中间区 → 判断变化页的十年记录 →「我的情况」对应说法。该日官方 PE 为 13.64 倍、第 58.1 百分位，新增资金由「暂缓新增」转为「按原计划，不额外追加」。

## 证据与实现

随包官方数据覆盖 2011-06-28 至 2026-09-30，共 3,788 个数据日。规则序列从 2016-06-28 开始，累计 31 次改变。**31 次均为历史回算，包含 2026-09-07，不是当时发布的判断；本次软件运行中改判为 0 次。** 新资料改变估值区域时，程序按同一规则确认并记录；失败保留最后可用数据与原日期。

「我的情况」只在本机保存计划、持仓与期限，同一规则分别说明尚无计划、已有计划、已有持仓的含义。解读文章以紧凑入口承接解释，资料与口径默认折叠。AI 研究链使用规则结果作为证据，并校验新增资金与持仓立场的一致性；AI 解读须用户自备 Key 与费用授权，规则判断和历史回算无需 Key。

## 落地与验证

rc.5 面向 Mac arm64 与 Windows x64。桌面和手机首页都按同一顺序呈现判断、我的情况与文章入口，安装包及三种情境的实际截图随发行提供。下一步以真实试读检查读者能否复述判断、找出改判条件、区分回算与实际记录，再探索个人订阅与机构公开研究内容服务。

## 边界

不预测涨跌、不保证收益。当前只覆盖沪深300与 007339、005658 两只联接 C 类，不替用户决定配置比例或执行交易；历史回算不证明收益有效性。尚无真实用户效果、银行合作或收入实绩，Windows 原生验收与真实付费基金 AI 研究效果待验证。文书待套正式模板并经本人、学校核对，尚未提交。
