# 经纬规则稳健性：换一组参数，结论还在吗

运行 `node scripts/rule-sensitivity.ts` 可得到下面的全部数字。脚本独立实现规则，不调用软件的规则代码；数据为随包的中证官方滚动市盈率与全收益指数（含分红），截至 2026-09-30。覆盖沪深300、中证500、上证50、中证1000、中证红利五个指数；中证1000从 2014-09-25 开始，其余从 2011-06-28 开始。

## 结论

- **有样本区间的排序在 49/50 次运行中成立。** 五个指数、十组参数的 3 年年化均值，按偏低 → 中间 → 偏高 → 高位比较有样本的区间。唯一例外是上证50 改用 7 年窗口时，偏高区（6.3%）高于中间区（4.8%）。50 次中只有 18 次四档样本齐全，其中 17 次完整排序成立；其余 32 次不能验证四档完整排序。
- **新增两项只能验证部分区间。** 中证1000十组参数都只有偏低区和中间区具备完整 3 年月初样本，现行 v2 的均值为 3.6% 和 -4.1%，偏高区、高位区没有样本；中证红利十组参数都缺高位区样本，现行 v2 的偏低、中间、偏高区均值为 9.7%、7.7%、2.9%。两者有样本的区间均依次降低，但不据此声称四档完整排序成立。
- **v2 的缓冲解决的是“反复改口”。** 同一数据上，沪深300 的改判从 31 次降到 17 次，45 天内反转从 7 次降到 1 次；中证500 的改判 17 → 9、反转 7 → 0，上证50 的改判 42 → 22、反转 18 → 2，中证1000 的改判 14 → 6、反转 7 → 0，中证红利的改判 27 → 17、反转 11 → 1。缓冲幅度取 5 点，是在“少反转”和“不迟钝”之间的折中：3 点仍有较多反转（上证50 7 次），8 点改判更少但偏低区样本更集中。选择依据是反转次数，不是收益高低。
- **部分区间样本很少。** 现行 v2 按月初取样，沪深300 偏低区只有 7 个、上证50 只有 2 个起点，持有期仍相互重叠；这一档的数字说明方向，不足以给出精确的期望收益。

## 怎么读这些表

- “3 年年化”按每月第一个交易日当天已确认的区间分组，计算之后 3 年含分红的年化收益；括号里是样本数。相邻月份的 3 年持有期仍有重叠，但比逐日取样少得多。
- “45 天内反转”指一次改判在 45 天内又改回原区间。
- “—”表示该参数下这一档没有完整 3 年的样本。
- “有样本区间依次降低”仅比较非空区间的未舍入均值，严格按偏低 → 中间 → 偏高 → 高位降低；“四档齐全”为否时，不能把这一列理解为四档完整排序。表格显示值保留一位小数。

## 边界

这是同一段历史上的检验，沪深300、中证500、上证50、中证红利从 2016 年开始给出规则区间，中证1000从 2019 年开始；截至 2026-09-30，只有三周年之后仍有全收益收盘值的起点进入表格。不是样本外验证，历史排序不保证未来。参数事先固定为整数常用值，没有为了收益做搜索。
