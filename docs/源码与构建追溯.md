# 本地源码与构建边界

2026-10-05 检查确认，本目录及其祖先均未建立 Git。本次从当前源码建立首个本地基线；此前 rc.1、rc.2、rc.3 没有对应源码提交，不补造发布历史。旧发行文件仅按已有文件 SHA256 与包内版号追溯，不能宣称可由新基线精确重建。

后续 `npm run build` 按已跟踪源码逐文件计算 SHA256，将版号、源码摘要、实际 Git 提交、未提交路径及构建时间写入构建清单。每次输出独立的 `apps/web/.builds/<build_id>`，成功后更新 current.json 指针，不覆盖上一构建。`npm start` 启动时将选中的 SSR 与静态资源一起复制到该进程专有快照，之后的新构建不改变已运行页面。桌面发行把同一份构建及清单封入 app.asar；.desktop-build 只作打包暂存，不作为用户安装版的活动资源。

本地 Git 无 remote，不 push。基线仅收源码、锁文件、产品文档、授权、图标与必要公开种子。运行资料、用户文件、凭据、日志、缓存、备份及安装包排除在外。当前 web/api/worker 使用文件存储；PostgreSQL 和 pg-boss 已移除。旧 SQL 设计保留在未跟踪的历史目录，无运行入口。
