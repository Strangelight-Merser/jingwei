## 数据来源与处理

- 中证指数官网 `indexCsiDsPe`：沪深300、中证500、上证50、中证1000、中证红利、科创50，每日滚动市盈率。
- 蛋卷基金指数估值 `djapi/index_eva/pe_history`：创业板指、纳斯达克100、标普500、恒生指数、恒生科技。中证指数官网不发布这些指数的估值，美股、港股指数也没有免费的官方长期 PE 历史，因此用第三方数据并在页面上注明“蛋卷基金（第三方）”。日期按北京时间取日。
- 中证1000 在 2014-09-25 以前的读数为 7–10 倍，当日跳到 49 倍，与之后的序列不是同一口径，种子从 2014-09-25 开始；科创50 有一条孤立的 2016-01-01 记录，种子从 2020-07-06 开始。其他指数的单日大幅变化保留不动。
- 种子由 `scripts/fetch-index-pe-seeds.ts` 生成；联网时按同一来源补齐新数据（蛋卷取近三年周数据合并）。
- 全收益来自中证指数官网 `index-perf`，对应 H00300、H00905、H00016、H00852（中证1000全收益指数 / CSI 1000 Total Return Index）、H00922（中证红利全收益指数 / CSI Dividend Total Return Index）。按代码和官方中英文全称校验，含分红、不扣基金费用；种子由 `scripts/fetch-total-return-history.ts` 生成，中证1000从自身估值起点 2014-09-25 开始，其余从 2011-06-28 开始，均截至 2026-09-30。ERP 只匹配同日的中国十年期国债收益率。
- 每个指数都有独立复算：`node scripts/replay-rule.ts --index NDX`，测试逐条核对改判记录与软件一致。

## 持仓体检

普通跟踪上述指数的基金（指数基金、ETF、联接、LOF）得到对应指数的判断；指数增强、行业或策略变体（如创业板50、红利低波、恒生医疗、纳斯达克科技市值加权）不套用，只计入方向与重复。


## 第三方数据与官方数据对照

2026-10-07 直接拉取两家公开历史接口，统一截至北京时间 2026-09-30，与本页覆盖表的截止日期一致。可复跑：

```sh
node scripts/compare-sources.ts --as-of 2026-09-30
```

不传日期时截止到运行当天的北京时间日期。脚本只读取公开接口，不读取本机用户数据，不更新种子或应用存储；接口后续修订历史值时，复跑数字可能变化。本次抓取开始时间为 2026-10-07T14:33:01.654Z。

来源：[中证指数官网每日 PE 接口](https://www.csindex.com.cn/csindex-home/perf/indexCsiDsPe)（参数 indexCode、startDate、endDate）；[蛋卷基金历史 PE 接口](https://danjuanfunds.com/djapi/index_eva/pe_history/SH000300?day=all)（六个代码分别为 SH000300、SH000905、SH000016、SH000852、SH000922、SH000688，参数 day=all）。中证读数校验指数中英文身份；蛋卷按请求代码取序列，时间戳转换为北京时间日期，PE 按软件当前处理保留两位小数。

计算口径：

- PE 差统一为“蛋卷 − 中证”，单位为倍。只配对日期完全相同的记录，不向前填充、不配最近交易日；P05 / P50 / P95 使用排序后位置 `(n−1)×p` 的线性插值，相关系数为 Pearson。
- 两家都从软件规定的有效起点截取：中证1000自2014-09-25、科创50自2020-07-06，其余自各自中证连续日序列起点。蛋卷若没有更早历史，就从实际首条开始。蛋卷同一北京时间周内可能有多条记录，按周一至周日分组、保留最后日期的一条，与当前软件周去重口径一致。五个指数各有516条原始蛋卷读数，去重后512周，其中509周有同日中证记录；科创50截取后有323条，去重后320周，其中318周有同日中证记录。缺少同日记录的周不进入表内配对统计。
- 分位各自按本规则复算：滚动10年、至少5年，含当期，计算窗口内“不高于当期 PE”的记录占比。中证用完整日序列，蛋卷用完整周序列，不用配对交集替代各自历史；分位差单位为百分点，计算用未四舍五入的分位。至少5年条件导致规则样本少于 PE 配对样本。
- “v2判断一致率”在规则可计算的同日周上比较四个已确认区间，含5个百分点缓冲；中证连续5个交易日确认，蛋卷连续2周确认。各自从第一个可计算分位初始化并完整推进，不在每个配对日期重新初始化。
- “同日周采样判断一致率”另将中证与蛋卷都限制为完全相同的配对周日期和起点，用相同10年窗口、5年最低长度、缓冲和2周确认。它控制历史起点及采样日期差异，观察两家 PE 数值本身带来的判断差异；不是软件中证日频规则的替代版本。

结果解读：

沪深300、上证50、中证红利的 PE 相关系数为0.95附近至0.99，但软件规则的判断一致率仍只有70.75%—81.03%。分位对各自历史窗口与日／周采样敏感，均值偏差接近零也可能伴随较大的逐期绝对差。因此不能把高相关系数解释成“两个来源可以直接互换”。

中证500与中证1000的蛋卷 PE 平均分别高4.69倍和11.35倍；对应分位平均高13.47和11.32个百分点。即使统一周采样，判断一致率仍分别为69.17%和82.21%，说明差异不只来自频率或历史长度。

科创50差异最大：PE 差均值28.75倍、P95为105.77倍，相关系数0.6890；软件规则判断一致率20.31%，统一周采样后为15.63%。其规则比较只有64个周样本，约15个月，历史不足十年。数据结果提示两家估值口径或历史计算可能不同，但本次接口数据没有给出足以解释差异的编制细节，不能把具体原因认定为已核实事实。科创50继续采用中证官方序列，不能拿蛋卷 PE 替换。

回答“境外指数用第三方数据可信吗”：本次可核实的是蛋卷对部分 A 股指数能反映相近的估值变化趋势，同时确实存在足以改变区间判断的来源差异。这次比较没有境外指数的官方 PE 对照，不能外推成纳斯达克100、标普500、恒生指数或恒生科技已通过准确性验证。当前境外判断应理解为基于蛋卷自身历史、同一来源持续计算的相对估值信号，引用时保留第三方来源和周频口径；跨来源的 PE、分位和区间不直接互换。
