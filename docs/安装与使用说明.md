# 经纬·规则e判 1.0.0-rc.5 安装与使用说明

经纬是一个桌面应用，Mac（Apple 芯片）和 Windows（64 位）各有一个安装包。安装和使用都不需要账号；阅读判断、改判记录、持仓体检都在本机完成，不上传个人数据。

## 安装

**Mac（Apple 芯片 M1 及以后，macOS 12 及以上；Intel 芯片的 Mac 暂不支持）**

1. 双击 `Jingwei-1.0.0-rc.5-mac-arm64.dmg`，把“经纬”拖进“应用程序”。
2. 第一次打开时，在“应用程序”里**右键点“经纬” → 打开 → 打开**。这是因为参赛版没有经过苹果公证，之后直接双击即可。

**Windows（10 / 11，64 位）**

1. 双击 `Jingwei-1.0.0-rc.5-windows-x64-setup.exe`。
2. 若出现“Windows 已保护你的电脑”，点**更多信息 → 仍要运行**（参赛版未做代码签名），按提示完成安装。
3. 截图识别持仓使用系统自带的中文文字识别；若提示缺少中文语言包，按提示在“设置 → 时间和语言 → 语言”中添加“中文（简体）”。

## 五分钟体验路线

1. **今日判断**：打开后先看首页。上方选择指数（A股 7 个、美股港股 4 个），看“新增资金”和“已有持仓”两种做法；拖动曲线回看历史；下方“全部指数”一眼看全 11 个指数。
2. **改判记录**：点首页“…的 N 次改判 →”，看已有历史里的每一次改判、各区间之后的收益回放（沪深300、中证500、上证50、中证1000、中证红利）和股债对照。页顶“‹ 今日判断”返回。
3. **我的 → 持仓体检**：拖入或选择一张基金持仓截图（支付宝、银行 App、天天基金等均可），确认识别结果后查看钱的去向、规则覆盖、按区间汇总和重复方向；可“导出体检报告”。没有截图时可点“粘贴文字”，每行写一只基金的名称和金额，例如“华夏沪深300ETF联接A 12000”。
4. **问经纬**：在首页对所选指数提问，回答只解释公开规则，立场与规则一致，不预测涨跌。需要自备 DeepSeek 密钥：先在桌面菜单“帮助”勾选“维护模式”，再打开设置（右上角齿轮）→ 模型连接，填写密钥与累计费用上限并勾选授权；授权长期有效，可随时撤销。
5. **机构服务**：看银行如何把同一条规则做成可嵌入的规则卡（11 个指数可切换），以及客户经理一页说明（可导出 PDF）。

<h2 style="break-before:page">常用操作</h2>

- 后退 / 前进：Mac ⌘[ / ⌘]，Windows Alt+← / Alt+→；菜单“前往”可直达各分区。
- 数据：随安装包附带截至 2026-09-30 的估值数据；联网时自动补齐新数据，并在页面标明数据日期与来源（中证指数官网，或蛋卷基金（第三方））。
