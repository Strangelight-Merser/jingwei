# 经纬：工行落地与价值测算

经纬适合嵌入工行基金渠道，提供公开估值解释、客户经理说明和持仓体检。先以说明效率与客户理解度验收，再验证持有行为。按下列假设，中性档年服务31.5万人、释放1.05万工时，折合105万元人力资源价值；银行采购内容与工具服务构成主要收入。

## 工行怎样用

- **手机银行**：建议放在“财富／基金→投教与投资陪伴”，基金详情页的风险收益说明区提供入口。经纬内从“机构服务 → 规则卡”（`/bank`）预览并复制嵌入代码，`/embed/rule-card`展示11个指数的估值、数据日期、规则区间及改判条件：A股为沪深300、中证500、上证50、中证1000、创业板指、科创50、中证红利；美股港股为纳斯达克100、标普500、恒生指数、恒生科技；`/embed/rule-card.json`供银行按自身样式展示。
- **客户经理**：先在银行系统核对客户测评、产品评级和投资期限，再从“机构服务 → 客户经理说明”（`/advisor`）填写长期计划、已有持仓、期限及可选金额，生成一页说明，逐项解释规则、来源和改变条件，提供PDF／打印入口。说明页表单不承担风险测评。
- **持仓服务**：在“我的基金／资产分析”提供`/holdings`入口；经纬内从“我的 → 持仓体检”进入。现有文字导入、手工录入，经客户确认后展示资金方向、跟踪同一指数的重复配置和规则覆盖部分；普通跟踪上述11个指数的基金（指数基金、ETF、联接、LOF）按对应指数给判断，指数增强、行业和策略变体不套用，只计入方向与重复；桌面版另有本机截图识别。客户经理据此开展持有期回访，银行持仓直连属于接入工作。

沪深300、中证500、上证50、中证1000、科创50、中证红利这6个指数使用中证指数官网每日估值；创业板指及4个境外指数使用蛋卷基金公开的每周估值，页面注明“蛋卷基金（第三方）”。中证不发布后5个指数的估值，境外指数也没有免费的官方长期PE历史，因此采用第三方数据。同一分位、分档与缓冲规则按频率确认：日数据连续5个交易日，周数据连续2个周读数，两者都约等于一周。收益回放和ERP覆盖沪深300、中证500、上证50、中证1000、中证红利五个指数；原29/30稳健性结果仍只适用于沪深300、中证500、上证50。科创50、创业板指和四个境外指数只给估值判断和改判记录。[指数覆盖](指数覆盖.md)

## 合规与业务边界

公募基金代销适用证监会[《证券期货投资者适当性管理办法》](https://www.csrc.gov.cn/csrc/c101953/c5359211/5359211/files/附件1.1：中国证监会决定修改的规章.pdf)（2022-08-12修正），第3、23—25条要求了解客户、充分揭示风险、确认及留痕。银行理财适用金融监管总局[《金融机构产品适当性管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1217183)（2025-07-11公布，2026-02-01施行）；第3条明确代销证券基金产品仍按证券基金适当性规定执行，第22条要求产品至少划分五级、评级孰高采用。

基金业协会[《基金募集机构投资者适当性管理实施指引（试行）》](https://www.amac.org.cn/xwfb/hydt/202005/t20200513_18820.html)（2017-06-28发布）规定：客户C1—C5，产品R1—R5；通常C1对应R1，C2—C4分别匹配不高于自身档位的产品，C5可匹配全部等级。产品风险由低至高常称低、中低、中、中高、高风险。偏股指数基金常见R3或R4，不能统一定为R3：[易方达007339交易页](https://e.efunds.com.cn/cart/aips?form=&fundCode=007339)显示R3（发布日期未标注，2026-10-06查阅）；[华夏通知](https://www.chinaamc.com/c/2026-01-01/920526.shtml)（2026-01-01发布）已将沪深300ETF及其联接等上调为R4。工行须采用实际销售评级。

协会[《公开募集证券投资基金投资者适当性管理细则》](https://www.amac.org.cn/xwfb/xhyw/202606/P020260612617672605532.pdf)（2026-06-12发布即施行）第7、11、14条要求测评有效期原则上不超过十二个月、销售评级不低于管理人评级、线上适当性嵌入流程并可回溯。

银行部署应定位为**投资者教育与规则信息披露**，不作具体产品推荐。现有“可分批新增／再平衡”及按客户情况细化的动作措辞有被识别为推荐或投顾的风险；上线前须由银行审校，将对客内容调整为估值事实与规则含义，隔离具体基金买卖、比例和执行入口，不能靠免责声明改变业务实质。交易流程仍由银行完成：有效测评→产品评级及期限匹配→风险揭示与客户确认→交易→留痕及回访。须揭示本金损失、市场波动、流动性、费用及跟踪误差风险，说明历史表现不保证未来、估值偏低不等于低风险；本工具不替代法定披露、适当性匹配或银行责任。

以下均为**经营假设，2026-10-06设定**：基数取手机银行累计客户6.3亿户；年度去重触达率分档，完成率均为10%；每位完成客户全年计一次服务，其中20%替代客户经理重复说明，每次节省10分钟，每工时成本100元。

| 年度测算 | 保守 | 中性 | 乐观 |
|---|---:|---:|---:|
| 假设触达率 | 0.1% | 0.5% | 1.0% |
| 去重触达人数 | 63万 | 315万 | 630万 |
| 完成人数 | 6.3万 | 31.5万 | 63万 |
| 释放工时 | 2,100 | 10,500 | 21,000 |
| 人力资源价值（万元） | 21 | 105 | 210 |

公式：完成人数＝6.3亿×触达率×10%；工时＝完成人数×20%×10÷60；价值＝工时×100元。累计客户并非活跃基金客户；工时价值是可重分配服务能力，不能直接记为现金利润。净价值还须扣除采购、接入与运营成本。试点记录去重使用人数、说明耗时和理解度，达标后再研究持有时长及赎回行为。

## 商业模式

收费对象为工行或其他持牌银行的财富管理、数字渠道部门：试点收固定接入费，正式服务收年度内容与接口授权费、客户经理工具席位费，按合同约定调用档位。成本包括数据商业授权与更新、内容及合规审校、接口联调与部署、计算及模型调用、运维和客户经理培训。银行采购价格与这些单位成本未查到公开数字，以试点报价及实耗核定；不向客户按收益抽成，不以刺激交易频率获取收入。
