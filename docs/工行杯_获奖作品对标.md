## 获奖作品的共同点

1. **标题公式**：品牌名——基于（技术）的（场景）（服务方案/平台）。品牌名大量借用工行的“e”系列，如工e、融e、工银。
2. **写明工行怎样用**：方案落在工行的具体业务或渠道上，例如手机银行、客户经理、某类贷款，而不是一个独立 App。
3. **踩政策主线**：“五篇大文章”（科技、绿色、普惠、养老、数字金融）以及当届设定的方向。
4. **AI 是标配，但讲分工**：例如“小模型判别+大模型生成”，判别交给可控模型，生成交给大模型。
5. **答辩是路演加犀利追问**：评委看重专业性、可行性和场景贴合度。

## 官方报告结构（附件4）

摘要 → 背景与痛点 → 作品介绍（架构图、数据来源、功能模块、用户流程）→ 创新点（技术/应用/模式）→ 市场前景与可行性（商业模式、竞品对比）→ 运营规划与风险评估（含合规与数据安全）→ 结语 → 参考文献。模板允许自主调整。

## 经纬的差距与对策

| 差距 | 对策（只用已实现的功能） |
|---|---|
| 没有讲工行怎样用 | 场景：工银手机银行基金频道的“估值规则卡”，客户经理用同一规则向客户解释；同一判断按“我的情况”给出不同说法，可对应适当性管理 |
| 标题没有套用公式 | 例如：《经纬·规则e判——基于公开估值规则与大模型解读的指数基金决策服务方案》（由本人决定） |
| AI 叙事偏弱 | 如实讲成“规则判别 + 大模型解读”：立场由公开规则确定，模型只解释，立场必须与规则一致（已实现并有测试）。真实付费模型尚未运行，答辩时如实说明 |
| 竞品追问：蛋卷、有知有行等估值温度计 | 区别在于：判断落到“新增资金/已有持仓”两个动作上；明确改判边界（12.42/14.24/15.33 倍）；5 日确认防抖；十年 31 次改判全部可独立复算；同一判断按个人情况给出说法 |
| 方向归属 | 第十七届“财富管理服务”方向，可兼顾“青年群体服务”（刚开始定投的年轻人） |
