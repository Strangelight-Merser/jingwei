# 经纬：技术与方法证据附录

核对日期：2026年10月5日。本附录独立于主稿和产品，说明设计依据及证据边界。

## 为什么这样设计

《Simplification and Saving》研究美国雇员退休储蓄，提示复杂选择可能造成拖延。[1] 经纬据此减少首次阅读所需的信息整理：先给具体判断及适用条件，再就地展开比较和原文。该研究使用预设缴费率与资产分配，经纬没有照搬默认组合，也没有据此声称能提高中国年轻人的参与率。另一项美国401(k)研究发现，制度设置与默认路径会影响选择。[2] 因而当前基金表的首个显示页只是阅读顺序，不预选基金、仓位或买入动作。

简化披露实验没有发现摘要招募说明书改变组合选择；缩短文档不能自动消除费用误解。[3] 同指数基金实验则提示，费用更显著时，选择会向低费工具移动，但仍未普遍达到最低费组合。[4] 经纬由此把同方向C类的服务费、赎回期限与资料日期放在阅读现场，并说明原文费率不等于实付成本。比较费用回答工具差异，不能成为市场看涨信号；不同期限、渠道与生效条件未经核实，就不给无条件排序。

FCA的投资教育页用“近期是否要用钱”“怎样退出”“能否承受下跌”等日常问题解释适用性。[5] 经纬把资金用途和原计划变化写入公开判断的条件，不要求先填问卷，也不把读者自检变成买入通行证。英国规则与具体金额要求未移植。第一财经与端传媒的文章提供标题、导语和正文层级参照；本项目采用单栏阅读、自然展开来源，借鉴的是呈现方法，未取得其用户效果数据。[6]

## 实际做了什么

当前公开规则覆盖11个指数：A股为沪深300、中证500、上证50、中证1000、创业板指、科创50、中证红利；美股港股为纳斯达克100、标普500、恒生指数、恒生科技。沪深300、中证500、上证50、中证1000、科创50、中证红利用中证指数官网每日估值；创业板指及4个境外指数用蛋卷基金公开的每周估值，页面注明“蛋卷基金（第三方）”。中证不发布后5个指数的估值，境外指数也没有免费的官方长期PE历史。11个指数使用同一套PE TTM近十年分位、30／70／90分档及5个百分点缓冲；历史不足十年时用全部已有数据，至少五年。确认按频率区分：日数据连续5个交易日，周数据连续2个周读数，两者都约等于一周。[指数覆盖](指数覆盖.md)

收益回放和股债对照（ERP）覆盖沪深300、中证500、上证50、中证1000、中证红利五个指数，它们有中证全收益指数和中国十年期国债收益率可对应；《规则稳健性》原有29/30结果适用范围仍为沪深300、中证500、上证50，最新五指数结果见《指数覆盖》。科创50、创业板指和四个境外指数只给估值判断和改判记录。持仓体检对普通跟踪上述11个指数的基金（指数基金、ETF、联接、LOF）给对应指数判断；指数增强、行业和策略变体不套用，只计入方向与重复。[指数覆盖](指数覆盖.md)

后台保留原文片段、修订号和资料日期；同一事件比较旧观点，跨事件通过专题承接。维持、补充与修正分开，生成草稿与刊发分开；重复核查时间不制造“新观点”。市场依据、配置条件与基金工具条款在当前沪深300文章中分层，旧版保留当时的来源。相关实现见`finance.ts`、`publication.ts`和`fund-updates.ts`。[8] 候选详情补入中报页码与短原句：同期间C类表现可并列，基准差额与年化误差分开，管理人披露不作独立复算。[11]

两次真实DeepSeek请求暴露了具体缺陷：首轮生成失败；第二轮草稿把2025年比较段落就地引用到2026年材料，刊发前经人工删改。[8] 来源ID存在并不意味着引用支持句义。本轮用这些保留输出开展免费离线审查，改进生成与刊发边界；离线样本能暴露已知错例，无法证明下一次真实模型已经少出错。

## 仍没证明什么

ForecastBench用尚未揭晓的未来事件检验预测能力。[7] 经纬借鉴“判断需等待后续证据检验”的思路，当前尚未建立概率预测评分、收益回测或用户对照实验，不能借其成绩证明收益。页面核查只证明所检查入口和展示行为；真人理解、阅读负担、中国用户适用性与首次配置指导仍待验证。本次在隔离Chrome用原生Tab定位，并用Space与Enter展开、收起首页条件、A类条款和文章来源三类折叠；方法与实际记录见[10]。项目贡献是把证据、条件性解释与观点修订连接起来，不声称首创。
