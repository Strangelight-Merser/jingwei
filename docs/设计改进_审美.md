# 经纬页面审美改进（2026-10-06）

依据当前截图：首页（1280 / 375）、判断变化页、客户说明页、嵌入卡。现状是结构已清楚，但视觉平均用力，没有焦点，看起来像文档而不像产品。

## 问题

1. **没有视觉焦点**：首屏全是同一种灰色小字，最该被看见的“现在怎么做”和“48.8”没有被突出。48.8 在指数卡、正文和刻度条里重复出现三次，但每处都不醒目。
2. **颜色语义不统一**：
   - 四个区间在刻度条里有颜色，但在动作标签、改判条件、表格中没有用到。
   - 四种动作的“持”字标签是同一个深灰色块，看不出区别。
   - 主色存在两套：front.css 里定义了蓝色 `#245df2`，链接用的却是酒红色。
3. **刻度条粗糙**：“48.8”数字标签压在“中间区”文字上；区间文字对比度低；当前区间没有被强调。
4. **改判条件是一串箭头长句**：嵌入卡用的“区间 · 分位 · PE 边界”三列表格清楚得多，首页反而更乱。
5. **术语提示放错位置**：“滚动市盈率 ? 百分位 ?”漂在页面最顶部，和内容脱节。
6. **“自上次以来”像告警**：灰底加红色竖条，而且即使“新增 0 个数据日，判断未变”也每次都显示，成了噪音。
7. **手机上三列指数卡太挤**：“按原计划，不额外追加”折成两行；刻度条上“偏高区/高位区”挤在一起。
8. **小字太多、太淡**：大量 11–12px 文字，颜色在 `#8b93a1` 左右，对比度不足。
9. **首页缺少数据画面**：判断变化页有十年曲线，首页没有任何图，可信度和视觉记忆点都弱。

## 改法

**A. 统一视觉语言**
- 只保留一种主色：酒红色，与 logo 一致。删除 front.css 里的蓝色。
- 四个区间定义一套语义色，所有地方共用：
  - 偏低：绿
  - 中间：石板灰蓝
  - 偏高：琥珀
  - 高位：玫红
- 每种语义色同时要有浅底色和可读的深字色，文字对比度 ≥ 4.5:1。
- 正文最小 13px；辅助灰字加深到对比度 ≥ 4.5:1。

**B. 首页首屏重排（桌面）**
- 指数切换做成紧凑的分段控件：一行，内容为指数名 + 区间色点。
- 主区左侧：
  - 区间徽标（语义色）
  - 大标题“按原计划，不额外追加”
  - 一个大号数字“48.8”，下方一行白话：“近十年里 48.8% 的日子比今天便宜”
- 主区右侧：复用 PercentileChart 的紧凑版，画十年分位小曲线，标出今天的位置。
- 48.8 只在大号数字处突出出现一次，其他地方去掉重复。

**C. 动作卡**
- 标签按动作着色：加 = 绿，持 = 石板，观察 = 琥珀，减 = 玫红。
- 新增资金和已有持仓两张卡，按区间色加左侧细边。

**D. 刻度条**
- 圆角轨道。
- 当前区间用实色加粗体，其他区间淡化。
- 标记改成轨道上方的圆点加数字，不再压住文字。
- 手机上区间名缩短，或改放在轨道下方。

**E. 改判条件**
- 改为与嵌入卡一致的三列小表：区间（带色点）| 分位条件 | PE 边界 | 对应动作。
- 手机上每行折成两行。

**F. 其他**
- 术语提示放到对应词旁边，删除顶部那一行。
- “自上次以来”：只在有新数据日或改判时显示；样式改为轻量的一行，不用告警样式。
- 手机端指数切换：横向分段控件，每项一行。

**G. 客户说明页和嵌入卡**
- 两处的区间徽标都用语义色。
- 客户说明页把“对你的具体说法”那一句做成视觉焦点（大一号、用区间色左边线）。
- 打印样式要保证：彩色打印好看，黑白打印仍能分辨。

## 约束

- 不新增功能，不改文案含义，不改数字来源。
- 不用渐变、阴影堆叠和装饰图标；靠层级、留白和语义色解决。
- 桌面 1280 与手机 375 都要截图验收。
